# 月饰少女 · 默认角色 v1

采用依据：用户选择 A 稿作为默认角色，并授权按项目需求补齐其他行走方向。角色原始设计为本次用户提供；右向 A 的来源是 JIBIJIBI 的 2026-10-06 三稿记录，复制后独立于该仓库运行。

[参考设计](reference.png) 与 [方向母图](masters) 保存身份输入。四方向母图的精确 ImageGen 提示词位于 `masters/*.prompt.txt`。右向 A 的[母图提示词](masters/right.prompt.txt)和[原始调用回执](masters/right.imagegen-receipt.json)已从原实验逐字节补存；回执里的原文件名由[便携来源映射](masters/right.provenance.json)对应到本项目文件，参考图与母图 SHA-256 均匹配。左、前、后母图使用 ImageGen 内置工具，各一张单角色、单方向图；工具未提供的内部版本及种子未伪造。H3 配方、固定种子、完整源视频、整段静态变换、连续步态选择与 Aseprite 回读位于 [generation](generation)。保留输入可复核后处理；重新调用生成工具不能保证获得逐像素相同的新图。

右向 A 保持原来的 27 帧及每帧 41/42 ms 时长。其他三个方向使用 768×768、56 帧、24 fps、40 步生成，ToonOut 抠图后直接导出原生 256×256；左/前种子分别 141/241，背向首稿 341 因转身被淘汰，背向替换稿为 442；参考中间帧 27。每作业一次提交预算为 1800 秒。来源中记录生成和像素化参数；后台模型与服务安装不属于游戏运行依赖。

## 资源要求与证据

| 要求 | 实现与证据 |
| --- | --- |
| 最大 256 原生分辨率 | 全方向 256×256 PNG；直接从 768 源帧像素化 |
| 保留轮廓及服饰纹样 | 固定整段裁剪、每方向 96 色共享色板、nearest、无 mipmap；完整源视频与像素预览保留 |
| 饰品随步态摆动 | 各方向提示词明确重力和轻微相位延迟；硬质月饰不弯曲、悬饰不脱离 |
| 裙摆自然运动 | 腰胯驱动褶裥与裙摆，按前后和侧面视角调整遮挡 |
| 发辫轻微跟随 | 保留双辫与红结，强调轻微延迟摆动，避免风吹效果 |
| 正确方向结构 | 左右为三分之四视角，前后为正面/背面；背面不显示胸饰和正面围裙 |
| 源帧完整时序 | 选择连续完整步态，原始 PNG 字节与每帧时长保留，不跳帧或插值 |
| 可编辑和独立运行 | 四个 `.aseprite`、四方向 PNG/图集及 JSON；资源复制进本项目 |

背向首稿与淘汰原因保存在 `generation/rejected-up-v1`，不混入运行资源。

生成式动画有少量细纹与发梢的帧间变化。技术回读、Agent 运动审阅、用户 A 稿选型和游戏接入各自记录；补生成不被表述为用户逐帧美术批准。
