# 江南河街驻点人物

三名人物由内置 ImageGen 各独立生成一次透明母图，原 PNG 字节保存为各目录的 `mother.png`。使用默认角色设计作画风和比例参考，没有覆盖或重生成默认角色。人物为三分之四朝向的完整静态站姿，本轮不追加行走动画。

| ID | 人物 | 服饰 |
|---|---|---|
| innkeeper | 掌柜 | 浅米长袍、暗棕腰带、银扣 |
| vendor | 摊主 | 靛蓝围裙、米袖、发簪与小银扣 |
| boatman | 船工 | 草帽、蓝布短衫、绑腿与布鞋 |

每个目录保存 `prompt.txt`、`receipt.json`、可编辑 `structure.json`、固定变换 `transform.json`、产物与检查 `build.json`，以及颜色／法线／材质蒙版的最近邻放大 `preview.png`。工具未提供内部模型版本或随机种子，来源记录中保留 null。

运行图位于 `assets/ancient-canal/npcs`，均为256×256，脚底锚点128,240，像素世界尺寸0.009米。颜色母图通过固定裁切、最近邻取样、最多96色的无抖动色板处理，完整轮廓和双脚保持在画布内。

法线源由人工根据母图可见姿态绘制头脸、鼻、发髻、耳朵、手、袖口、裤腿、衣褶、鞋和草帽的独立语义几何层。`structure.json` 的椭球面与折线衣褶可以分别编辑，母图色彩亮度、阴影及颜色边缘没有用于生成法线。法线采用线性向量数据和 OpenGL 方向，X向右、Y向上、Z朝镜头；不做颜色量化或抖动。

材质蒙版R表示银饰高光区域，G表示粗糙度，B表示金属度。布料默认粗糙度0.93，银饰0.24。A与颜色Alpha完全相同，法线Alpha也逐像素相同。当前角色受光材质读取R，其他通道保留供材质扩展。

离线重建入口为 `tools/ancient_canal/build_npcs.py`。它读取已归档母图和结构源，不调用生成服务。运行包只需要生成后的PNG，不需要制作工具或其他仓库。

所有原图及最终像素图已做视觉审阅，三套产物通过色数、尺寸、Alpha配对和法线长度检查。场景GPU受光、NPC交互与投影阴影由演示场景整体验收提供证据，本目录的数据检查不替代这些检查。
