## 布局意图

后巷、建筑、院坪及摊位、后岸街、河道、前岸步道形成前后层次。四栋建筑沿 X 错开、沿 Z 小幅前后变化；中央桥轴留出 6.8 米空隙，通往后巷。酒肆西侧靠近码头，门前留出 7.8×2.7 米院坪。布摊服务左侧住户和码头；食摊、茶摊分布在东侧，错开住宅正门。三摊复用现有布摊／食摊模型，茶摊暂只定义使用功能。

后岸街宽 2.8 米，码头入口处保留至少 2.2 米连续通行宽度；摊前另设约 0.8 米停留带，NPC 置于院坪或摊侧。前岸步道宽 4.2 米，提供横移和桥头转向空间。建筑入口各设 1.6 米净宽的接街通道；平面柳树在边缘取景，三棵近景树保留原数量。后方六层视差保留，本图不审批远景装饰的具体摆位。

河中心 Z=2.5、宽5.2米；桥中心X=1.2、跨度8.4米、桥宽2.8米、桥面最高Y=0.6；码头顶面Y=−0.32；地图X=±26、Z=−16～14保持。
