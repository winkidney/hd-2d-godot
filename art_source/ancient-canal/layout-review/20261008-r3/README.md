## 数据与性能设计

图纸、[完整坐标 JSON](layout.review.json)和[摆放 CSV](placement.csv)由同一数据生成。CSV 保留柳树编号，并包含前景建筑、背景房屋与树群、两岸柳树、灯光、NPC、码头、小船和桥，共 42 个对象。坡道、道路范围和尺寸另见 JSON。

图纸采用 Godot 坐标，页面上方为 −Z 后岸，下方为 +Z 前岸；正视图从 +Z 看向 −Z。建筑尺寸取模型包围盒，摆放坐标是节点原点。正视图门窗和树冠是结构示意，不能作为实际 F/W 相机遮挡或 GPU 画面的验收证据。

保留 R2 的六座近镇房屋、四座远镇房屋和十处平面背景树群；背景关闭碰撞和阴影。前岸保留的两棵柳树投影，后岸柳树不投影。本次去掉一个平面树对象及其阴影，不新增光源；实际性能变化仍须在方案应用后测量。
