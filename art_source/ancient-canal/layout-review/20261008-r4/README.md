## 灯位安排

标出六盏灯笼 E1–E6、六盏路灯 P1–P6 和两处大范围光源 C1 / W1，共十四处。前版图纸只标了大范围光源，本版补齐灯笼与路灯。所有位置都是对应 R3 建筑布局的提议坐标，不代表当前运行场景中的位置。

C1 保留在桥心，W1 保留在酒肆前。P1 / P3 在前岸桥头两侧，P2 / P4 在后岸桥头两侧，P5 靠布摊与后岸街。E1 / E2 挂酒肆檐下，E5 / E6 放酒肆门口，E3 / E4 随民居二移动到其檐下。灯笼沿用原有顺序，对应 `lantern_0` 至 `lantern_5`；路灯与大范围光源保持现有控制 ID。

码头设置 P6 暖色路灯，复用既有 `streetlamp_dock_south` 和街灯模型，将它移到新码头木板西侧靠坡道的角落。灯柱脚点 X=−12.78、Y=−0.32、Z=4.9，脚点及半径 0.12 米的灯柱碰撞完全落在木板内，不占坡道。灯柱高 2.6 米；实际光源 X=−12.78、Y=1.88、Z=5.26，即高于木板 2.2 米。其局部暖光照向木板、接岸坡道和邻近水面。

P6 设计半径为 4.5 米，默认强度沿用路灯组，关闭阴影。应用时通过既有单灯参数为该 ID 设置 `range=4.5`、`shadow=false`，保留单灯隔离和设置 schema 2。其它路灯维持 4 米设计半径，灯笼为 4.5 米，大范围光源为 7 米。色彩为现有参数的设计基准色，实际仍随时段、分组和单灯参数控制。

## 性能与验证范围

本轮复用原码头街灯，新增光源节点数量为零，投影灯数量也不增加。码头灯关闭阴影，避免新增点光源阴影更新。其半径从路灯组默认 4 米提议调整到 4.5 米，实际 GPU 成本不能从图纸推断，应用后仍需在同布局上测量。

R3 的建筑、树木、码头、船和 NPC 坐标保持。码头入口处仍留有 4 米连续通行宽度。新增标注的路灯脚点避开桥体和两岸主通行中心线，P6 脚点位于木板内且避开坡道。[静态几何检查](review-checks.json)还核对十四个控制 ID、灯具偏移、灯柱占地，以及运行源码指纹保持。该检查不代替应用后的真实相机、灯光、碰撞和 GPU 验收。

## 来源和重建

基础为 [R3 设计数据](../20261008-r3/layout.review.json)。灯具 ID、模型光源偏移、柱高和碰撞半径来自项目 [layout.json](../../../../resources/ancient-canal/layout.json)；范围和基准颜色来自 [parameters.json](../../../../resources/ancient-canal/parameters.json)。酒肆与民居灯笼按建筑平移量接入新位置；布摊街灯按摊位横移量调整；码头灯脚点为本次人工设计。未引入外部素材。

源为 [draw.py](draw.py)，由同一份 JSON 生成图纸、两份 CSV 和检查结果。使用 Python / Matplotlib、DejaVu Sans 与系统 Droid Sans Fallback，无随机美术；SVG 标识盐与 PDF 日期元数据固定。重建方式：

```sh
MPLCONFIGDIR=/tmp/ancient-layout-review-mpl python3 art_source/ancient-canal/layout-review/20261008-r4/draw.py
```
