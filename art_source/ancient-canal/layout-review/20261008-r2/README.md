## 坐标和性能设计

俯视图上方为 −Z 后岸，下方为 +Z 前岸；正视图从 +Z 看向 −Z，横轴 X、竖轴 Y。尺寸均为米。主图包含近镇，远镇分图使用独立 X/Z 坐标轴，没有压缩真实纵深；完整俯视图将全部对象放在同一个等比例平面上。

建筑投影和高度来自现有模型包围盒。摆放坐标指模型节点原点，屋檐矩形中心不能代替节点原点。远镇 F2–F4 保留 Y 方向 1.1 / 1.2 / 1.3 的变化；数据中的包围盒已包含这个缩放，不应再次缩放包围盒。正视图门窗、檐口、树冠为结构示意，远近以色彩表达；它不是实际 F/W 相机投影或 GPU 渲染。

近镇六座、远镇四座房屋复用现有背景数量和资源。背景树群十处使用平面素材，关闭碰撞和阴影；两岸六棵柳树仅前岸三棵保留阴影。与最初“近景三棵、背景五棵”的树木方案相比，本版增加三个岸边平面树和五个背景平面树。上述做法控制设计成本，实际 GPU/CPU 增量仍须在应用后测量，不能由图纸推断。

[完整设计数据](layout.review.json)为摆放依据，[坐标表](placement.csv)包含前景建筑、背景房屋与树群、两岸柳树、灯光和 NPC。桥、码头、小船及街道尺寸另在 JSON 中记录。五名驻点 NPC 的编号 1–5 分别为掌柜、摊主、食摊摊主、茶客、船工。

## 来源、生成与检查

模型尺寸来源为[江南模型清单](../../blender/manifest.json)、[低桥清单](../../blender/low-bridge/recipe.json)和保留的 [R1 设计数据](../20261008-r1/layout.review.json)。新增植物与背景层位置是本次人工设计坐标，未引入外部素材。

[静态检查](review-checks.json)通过：前景屋檐在地图内，前景及背景建筑之间无屋檐重叠，主街与桥轴没有屋檐侵入，四个入口通道无遮挡，六棵柳树树干在岸沿且避开桥与码头入口，背景对象在可行走范围外且关闭碰撞与阴影，冷光位于桥中央并保留原控制编号。运行源码指纹与绘图前一致。此检查不代替应用后的碰撞、相机遮挡和性能验收。

源文件 [draw.py](draw.py)以同一份 JSON 生成所有图纸、CSV 和检查结果，使用 Python / Matplotlib、DejaVu Sans 与系统 Droid Sans Fallback；无随机美术。SVG 标识盐及 PDF 日期元数据固定。重建方式：

```sh

```
