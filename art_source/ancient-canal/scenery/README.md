# 平面柳树与自然夜空来源

本项目原创、固定种子 20261008 的离线程序化像素资源。用 `python3 tools/ancient_canal/build_scenery.py` 重建；详细参数、产物尺寸和 SHA-256 见 recipe.json。没有运行时生成、外部贴图或星节点。全景包含连续倾斜银河、离线多尺度亮区、暗尘带、18000 个星点及约 0.75° 细弯月。两侧像素列相同，使用 mipmap。

柳树包含树干、枝架与垂枝树冠，透明背景，锚点 (96,248)。运行时固定 Y 朝向镜头，透明裁切、mipmap；近景三棵投影、背景五棵关闭投影。旧三维柳树来源和模型保留。
