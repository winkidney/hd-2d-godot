# 操作与预览

## 启动

在工程根目录运行 `make run` 默认进入江南古风场景，也可用 `make canal-run` 显式运行。编辑工程用 `make editor`，F5 运行主场景江南河街，F6 运行当前单独打开的场景。

原默认驿站仅作存档和参考，使用 `make waystation-run` 或单独打开后 F6；`make p9-run`、`make frontal-run` 分别打开历史参考场景与正面运河。

| 场景文件 | 内容 |
|---|---|
| `scenes/ancient_canal.tscn` | 当前默认：江南河街、逐帧法线与中文光影控制台，F/W 镜头 |
| `scenes/waystation.tscn` | 存档：原默认 P6/P7/P8 驿站 |
| `scenes/reference_scene.tscn` | 存档：P9 A/B/C/D 四方案 |
| `scenes/reference_scene_graybox.tscn` | 存档：同布局灰盒 |
| `scenes/frontal_canal.tscn` | 存档：正面运河 F/W/O 与镜距/FOV |

静态世界保存在场景中，灯光、玩家和HUD在运行时组装，因此编辑器未运行时不会完全呈现最终照明。
`GODOT` 环境变量可指定已有引擎。启动工具只读取现有图形会话，不新建显示服务或更改桌面、防火墙。

## 江南主场景操作

WASD／方向键行走，E 交谈或调查，M 打开／关闭中文光影控制台，T 切换时段，G 开始自动路线，K 保存截图。面板关闭时滚轮调整当前 F／W 镜距。移动键或 Esc 可以接管自动路线，Esc 逐层关闭弹出选项、面板和对话；退出需确认。

控制台提供角色材质、场景照明、环境效果、比较与复现四页，包含法线开关、逐帧查看、单灯测试、近远景深及设置保存。详细参数、截图位置和建议路线见[江南河街说明](../ancient-canal/README.md)。Tab 只导航焦点，文本编辑和修饰键不触发普通操作；F8／F9 留给编辑器。

`make export`／`make package` 使用江南交付流程。历史运行包保持原入口和原内容，本次不重新制作。

## 存档场景操作

F8是Godot编辑器停止运行，F9可能暂停游戏，不能再用于打开游戏面板。游戏功能使用字母键或左上方按钮，不需要修改编辑器设置。

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 相机相对移动；斜向归一化 |
| E | 与附近NPC/招牌交互，再按关闭 |
| T / 1 / 2 / 3 | 循环时段 / 黄昏 / 夜晚 / 晴昼 |
| G | 展示模式，禁止玩家手动行走 |
| V | 景深、雾、泛光和SSAO总效果对照 |
| F | 有限跟随开关；展示模式优先 |
| B | 独立景深开关 |
| O | 景深调参面板 |
| P | 视差和跟随参数面板 |
| C | 相机比较面板；正面运河另含镜距18–45m、FOV25–60°；驿站无此面板 |
| K | 远景对照，天空与地面保留 |
| H | 隐藏/恢复HUD，世界仍运行 |
| Tab / Shift+Tab | 下一项/上一项界面焦点，不关闭面板 |
| J | 完成绘制后保存截图 |
| Esc | 关闭弹出菜单，或停止预览，或关闭面板，或关闭对话；否则先确认退出 |

数值框获得焦点后，字母和数字只用于编辑。其他场景裸键不接受Ctrl/Alt/Shift/Meta修饰键。
退出框默认选择Keep playing；点击窗口关闭或Exit按钮也先确认。自动路线期间仅接受裸Esc取消，结束或取消后恢复原状态。
关闭面板不自动保存。正面运河F/W/O镜距与视野分别保存，使用Save lens显式保存；视差设置仍在独立文件中。

## 推荐检查路线

驿站从出生点接近旅店NPC，按E调查；过桥后调查招牌，再到南岸30m横向石路左右往返。水域、建筑和栏杆不可穿越。默认跟随即产生横向视差，无需开启G展示。
V比较材质和角色的后处理，F检查跟随稳定性；B关闭景深后反复切V或时段，不应重置景深选择。H隐藏界面后按J截图。
参考场景和正面运河的C面板提供统一物理行走路线，Esc取消。

## 输出与排障

J截图写入本应用`user://captures/`，终端显示实际路径。自动验收截图位于各自`build/`证据目录，不混入手动截图。
黑屏或Vulkan失败先检查现有驱动和图形会话，不悄悄切换Compatibility。无桌面可运行`make test`和`make input-test`，不能据此宣称视觉通过。
`make input-window-test`在隔离副本中启动真实GPU窗口，依次测试四场景的独立运行和编辑器运行。只操作它启动的窗口，不改变日常设置。
导入异常用`make import`；改模型或布局后重建。`GODOT`可指定已有引擎，无需安装新依赖。

详细视差参数见[P8操作](parallax.md)，输入修复原因与证据见[输入安全验收](../validation/input-safety/README.md)。历史交付ZIP保留原版本、旧键位和旧截图，本次源码修复不等于重发了那些包。
