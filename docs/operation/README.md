# 操作与预览

## 启动
在工程根目录运行 `make run`；编辑场景用 `make editor`，打开 `scenes/waystation.tscn` 后按 F5。静态世界保存在 `scenes/world.tscn`；灯光、玩家和 HUD 在运行时组装，因此编辑器未运行时不会完全呈现最终照明。
`GODOT` 环境变量可指定已有引擎可执行文件。远程启动工具只读取现有图形会话，不新建显示服务、不改桌面或防火墙。

| 输入 | 行为 |
|---|---|
| WASD / 方向键 | 相机相对移动；斜向归一化；角色脚底为物理原点 |
| E | 与范围内最近的 NPC/招牌交互；再次按下关闭 |
| T / 1 / 2 | 切换 / 直接黄昏 / 直接夜晚 |
| F2 | 展示模式：轻微镜头运动，禁止玩家移动 |
| F3 | 同时切换景深、雾、泛光与 SSAO，用于效果对照 |
| F4 | 固定方向下的有限跟随；展示模式优先 |
| Tab / H | 隐藏或恢复 HUD；世界仍运行 |
| F12 | 实际完成绘制后保存截图 |
| Esc | 对话中关闭对话；否则退出 |

## 推荐检查路线
先在出生位置比较黄昏/夜晚，然后接近左侧旅店门前的 NPC 按 E；关闭对话，向石桥行走，过桥后调查右侧招牌。沿河岸尝试进入水域会被阻挡，桥栏和建筑也不可穿越。
按 F3 比较后处理关闭时的材质和角色；F4 测试移动中的像素稳定性。Tab 隐藏界面后按 F12 拍摄。

## 输出与排障
F12 存入应用 `user://captures/`，终端输出实际路径。自动验收截图在 `build/visual/`，不会混入用户手动截图。
黑屏或 Vulkan 初始化失败先检查已有显卡驱动和图形会话；不要为绕过问题悄悄改成 Compatibility。无桌面时执行 `make test`，它不能代替视觉验收。
资源导入异常用 `make import`，修改 Blender/场景布局后按素材流程重建。没有窗口时查看 `build/logs/`；`make test` 将 Godot 日志中的 ERROR 也视作失败，即使引擎退出码为 0。
