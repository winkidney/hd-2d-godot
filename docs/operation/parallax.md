# P8 · 视差调参与本机设置

## 立即使用
`make run` 启动后，沿石桥到南岸30m横向步道行走；按 F8 打开视差面板。F6仍为景深面板，两者互斥。
Basic页选择 Natural / Soft / Enhanced / Custom；拖动总强度会自动切入 Artistic。
Advanced页分别调三层山脉、两层云、横向相机参数和风。滑杆与数值框同步，各字段可独立Reset。
面板打开时停止人物手动移动，调整实时生效。Close或F8关闭；不自动保存。
Esc先停止镜头对照，再关闭面板；隐藏HUD会关闭面板并释放输入锁，不留下看不见的阻塞。

## 倍率的准确含义
1.0保持该层自然投影；0.5是该层自然横向位移的一半；2.0是两倍。
Natural模式强制有效倍率为1，但保留自定义值。Artistic的有效倍率=clamp(总强度×逐层倍率,0,2)。
请求值、正在应用的值和上限提示分别显示；背景不会因为请求4.0而在界面显示4.0、实际却不说明地限制为2.0。
0仅抵消五个装饰层的横向相机视差，不停止云风、不隐藏山脉，也不停止近场房屋与道路的正常三维运动。
地形、远处林带、角色、建筑和碰撞不参与补偿。天空按方向绘制，没有横向倍率。
不同深度的层即使倍率相同也不同速；px/m读数采用当前相机的逻辑视口尺寸，画面缩放后显示像素应同比缩放。
当远层的预计屏幕速度超过近层时显示层次反转警告，但不擅自更改参数。

## 镜头和风
相机横向跟随0–0.7、死区0–3m、平滑响应1–10/s、单侧限幅0–7.5m。原始默认来自world_layout.json。
纵深跟随倍率和死区不随横向覆盖改变；较小跟随/限幅可能弱化视差，应以实际路线构图判断。
两层风速分别支持-2–2m/s，0暂停单层；Wind enabled停止两层相位。调速不会重算历史位移。
参数过渡0–1s限制倍率变化速度；相机自身位移不再叠加第二重跟随滞后。

## 可选镜头对照
Start camera comparison在安全范围内横移镜头，冻结云和水面。它不传送玩家；到达相机限位时可能拒绝启动并提示。
Stop / Esc / 切换面板 / 隐藏HUD会恢复进入前的相机、跟随、时钟和景深状态。
正常步道行走才是实际玩法；镜头对照只用于排除云运动等干扰。
