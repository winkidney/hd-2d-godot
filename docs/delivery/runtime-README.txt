HD-2D / Riverside Waystation — Linux desktop preview

Run ./waystation.x86_64 from this directory.
If needed after extraction: chmod +x waystation.x86_64
No Godot editor or Blender installation is needed to run this bundle.
Requires Linux x86_64 and a Vulkan-capable desktop GPU/driver.
Tested on Fedora 43 KDE, RTX 4070 SUPER, NVIDIA driver 580.142.
Other platforms/hardware are not claimed as tested.

Controls:
WASD / arrows: walk. E: interact or close dialogue.
T: dusk/night. 1/2: select dusk/night directly.
F2: camera showcase (walking disabled). F3: effects comparison.
F4: limited camera follow. Tab/H: hide interface.
F12: save a screenshot to this application's user://captures/ directory.
The resolved screenshot path is printed in the terminal.
Esc: close dialogue, otherwise quit.

This is original procedural art and code for an interactive scene study.
It is not an extracted or official Octopath Traveler scene.
No combat, inventory, quests, indoor world, audio, or real reflected water.
ImageGen and Blender MCP are not connected or required by this executable.
