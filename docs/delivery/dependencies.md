# 依赖与风险登记

| 依赖 | 用途 | 本轮策略 | 风险 |
|---|---|---|---|
| 已装 Godot | 编辑/运行/导入 | 复用，不升级 | 版本与模板须匹配 |
| 已装 Blender | 建模/保存/GLB 导出 | factory startup，禁自动执行，项目脚本 | 不打开未知 blend 文件 |
| Python + Pillow | 纹理/图集/校验 | 复用已装版本 | 不全局 pip install |
| Godot export templates | 独立 Linux 包 | 官方版本+官方 checksum 验证后才使用 | 暂缺，待验证 |
| Blender MCP | 可选交互建模 | 未安装/未启用，需用户处理 | 任意 Python / 未认证 Socket / 第三方供应链 |
| ImageGen | 美术候选 | 非运行依赖；本轮先用原创程序素材 | 一致性与原图留存 |

## MCP 后续安全条件
固定审阅过的 commit/依赖锁，关闭遥测和第三方素材服务，不写入密钥；单独 Blender 进程，仅绑定 127.0.0.1，用完退出。
不要公开 9876、不要把未知自然语言转换为任意系统命令。建议独立用户或受限容器与专用项目目录。
本工程提供 Blender CLI 流程作为无需 Socket 的替代，不伪称通过 MCP 完成。

无 root、驱动、系统包、开机服务或防火墙变更；不写入宿主 Codex 配置。
