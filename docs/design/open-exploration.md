# 开阔探索与视差设计

本页记录 P6/P7 的实际构图、路径、背景与景深参数。

## 路线与镜头
出生点位于北岸广场，沿桥向南走，再沿横向石路左右行走。
路径长30m、宽3.2m，方向与相机水平right轴一致；路径两端仍可进入附近草地。
默认约11.9度俯角、10度方位、35度垂直视野，远裁剪1400m。
默认跟随开启，gain=0.45，dead_zone=0.8m，横向上限7.5m。
相机位置与观察目标同步平移，不用相机绕转来代替背景视差。
原高俯角画面只保留作历史对照，不要求进入独立模式才能看到天空。

## 背景
三层山体用 Blender 原创多面网格和顶点颜色制作，较远层更浅、更低对比度。
两层云复用三张像素云图，世界风速0.6和0.25m/s；天空不因横向平移滚动。
晴昼、黄昏、夜晚同步灯光、天空、山色和云；晴昼降低窗户发光。
草地过渡复用原场景材质，远处林带使用一个MultiMesh，不添加背景碰撞。
近场体积雾长度100m，方向光阴影85m，不随远裁剪扩大；远山用手工大气色。

## 景深
标准档amount=0.105，清晰区为焦点前6m、后10m，过渡范围近5m、远18m。
人物接近清晰区边缘才平滑追焦，展示模式固定场景锚点，手动模式用于调参。
强档用于效果比较；不追求让远山完全锐利，也不把它们模糊到无法辨认。
山体与云形仍是程序化视觉基线，自然形态和材质精细度可继续迭代。
