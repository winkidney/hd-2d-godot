# 设计要点与视觉 Review

## 当前主画面
旅店和石桥构成视觉中心；道路把前景引向玩家，树木分隔远景与主活动区。场景有真实高差和厚度，不是将整张概念图投在平面上。
角色使用 32×48 像素单帧，四向图集；物理位置固定在脚底，受三维灯光影响。环境采用低复杂度模型与最近邻采样的纹理，而输出保留 1920×1080，不使用全屏低分辨率缩放。
主镜头为 35° 透视，固定方向；景深仅模糊前后景，主活动区保持清楚。F3 是判断几何、纹理和受光是否成立的对照，不是隐藏问题的备用画面。
黄昏用暖主光和较冷环境补光；夜晚用蓝色环境与暖窗光。灯光预设作为一个值对象原子应用，角色与场景不重建。

## 材质与渲染约束
纹理通过世界坐标三平面投射，维持模块间密度；当前固定 texture_scale=0.55。改密度必须同时检查石材、木材、屋瓦与角色比例。
像素角色和植被使用裁切透明而非普通混合，减少透明排序歧义；角色有平面接触阴影与真实投影。Billboard 不等于有体积的角色，侧向光仍有局限。
水面为不透明风格化波纹与直接光照高光；没有 SSR、倒影贴图、岸线深度求交或水体物理。画面中灯光斑不是建筑倒影。
采用 MSAA、未开 TAA，避免默认引入明显时域模糊；远处纹理仍需运动中观察采样闪烁。

## 当前限制与下一轮优先级
当前为程序化原创美术基线，不冒充 ImageGen 生成结果。植被形态较重复、角色细节较粗、场景边缘有明显微缩底座；这些是待用户评审的美术工作，不是自动测试可判定的完成项。
下一轮建议先锁定主镜头与角色比例，再替换旅店、树冠和角色的人工/生成美术；随后再评估更自然的地形边缘、少量飘叶/烟雾、灯火动态。没有实现的增强项不列为已交付功能。
目前是单一场景模板，无角色法线、体积角色、自遮挡、室内、音频、战斗或完整 RPG 数据系统。

## 视觉验收问题
人物能否在暖灯下和阴影中保持辨识度？桥上行走时脚底与护栏遮挡是否可信？F3 关闭后材质是否仍协调？F4 跟随时有无明显像素闪烁？昼夜是否改变氛围而不是只是整体调暗？
最终风格认可由用户决定；ADR 03/06 的 Proposed 不因功能测试通过而自动转为美术批准。参考[实测报告](../validation/baseline-report.md)、[素材替换](../assets/README.md)和[研究来源](../research/README.md)。
