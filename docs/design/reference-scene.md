# P9 灯笼水城 · 设计与资源拆解

参考原图：砖砌水闸拱桥、左侧河岸、右侧市场广场、两组上层楼梯、深绿色栏杆、意式灰泥建筑、灯串与深青色水道。
已批准扩展概念图用于密度、照明和延伸方向；不会作为整屏游戏背景贴进去。
一张图不能确定背面/高差/尺度：新场景的不可见结构和延伸区属于设计推断，不声明为原作模型还原。

## 核心结构与镜头
主桥横跨纵向河道，拱门和铁闸是真实模型，桥面可走；两岸是砖砌台地。
右侧广场连接2.8m高上层街区；中央和右侧楼梯都有可见踏步与连续坡面碰撞。
1.5m落差的小阶梯连接右岸码头；左右街道总横向范围约46m，经过桥梁连通。
主相机依参考图重新标定，固定角度和透视；P6/P8预设、倍率语义、面板和约束继续复用。
新场景采用独立preferences_path与layout_id，不能覆盖旧场景镜头设置。

## 细分生产清单
| 类别 | 输入 / 生产方法 | 实际产物 |
|---|---|---|
| 表面材质 | 已批准ImageGen板正面裁切、64px归一化、无缝边缘和量化 | 红砖、地砖、石材、灰泥、屋瓦、木材、棚布、绿色、水纹 |
| 立面 / 道具图案 | 已批准候选去背景、硬Alpha | 门、两种窗、花箱、吊旗、菜单、花盆、灯笼图案 |
| 派生材质 | 绿色与白布交替条带 | 条纹棚布 |
| 主角 | 三个来源姿态、左右镜像、下肢有限后处理 | 48×64单帧、4×4图集；不是完整AI动画 |
| NPC | 商贩、店主、面包师、贵妇四个front来源 | 前向静态角色图集，重复帧仅适配旧Sprite接口 |
| 结构模型 | Blender源脚本 | 拱桥闸门、台阶、柱、栏杆、挡土墙 |
| 建筑模型 | Blender壳体+ImageGen纹理/门窗 | 主楼、小楼、塔楼 |
| 道具模型 | Blender+原图派生材质 | 摊位、灯柱、桶、箱、码头、长椅、船、花箱 |
| 衍生远景 | 相同建筑模块分三层缩放、重新布置 | 近城、中城、远城三层；复用视差ID |

## 表现边界
水面为风格化流动、光泽和水纹，不宣称真实几何倒影。原图已经绘制的光照不能从颜色图完美逆推。
先保证主角、拱桥、两条楼梯、平台与摊位的结构可辨认；最终材质密度和灯光由真实GPU截图调整。
