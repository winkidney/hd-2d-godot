# 美术方向 · Riverside Waystation

## 主画面
石桥连接旅店前广场与河对岸小路；暖色窗光/灯笼是焦点，河水与远景保持低饱和冷色。
前景树叶/芦苇形成框景，中景人物与桥保持清晰，远景建筑和树木减弱对比。
建筑不是写实 PBR 简单降采样：采用砖、木、瓦的成组像素结构，控制调色板与密度。

## 初版规格
角色逻辑帧 32×48，4 朝向×4 帧；透明裁切、脚底统一。人物与房屋按世界尺寸校准，禁止靠 fixed_size 保持屏幕尺寸。
环境纹理以 64/128px 可平铺图为主，色彩有分组而非逐像素白噪声。树叶为原创透明像素卡片。
模型：旅店、附屋、石桥、码头、灯笼、路标、货箱、木桶、树木；保留 editable blend 与生成器。
首轮素材为原创程序化图案/精灵，不宣称已经使用 ImageGen。程序化只是可重建基线，用户可要求替换/深化。

## ImageGen 后续入口
先批准角色基准帧与场景构图，再生成单独资产；不要把概念图冒充运行截图。
每项归档原图、提示词、生成日期、处理参数和 SHA-256；不同朝向/动画需要检查衣饰一致性。
法线为增强项：与颜色图共用画布和 Alpha，校验方向和结构配准；不得自动信任 AI 法线。

## 画面审查
关闭景深/泛光/雾后仍需可读；禁止过度 DOF 让主体或桥路失焦。
检查色温一致、落地阴影、遮挡次序、窗灯亮度、纹理比例、移动闪烁、图集帧抖动。
高保真目标与当前基线差距必须记录，最终艺术批准由用户作出。
