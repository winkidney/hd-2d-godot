## 测试中修复的问题
夜景参数对照最初混入了雾的时间稳定过程；现每个对照机位等待120个实际绘制帧，再进行像素比较。
发布版stdout缓冲会让故意损坏配置产生的stderr错位到其他断言行。验证器仅接受一次精确匹配的预期损坏文件错误，并要求对应拒绝断言通过；原始日志保留，其他ERROR仍使验证失败。
面板增加常驻有效倍率摘要，高级页调节时仍可看到实际近/中/远倍率。

## 结果边界
山体覆盖使用AABB投影检查，并另审查极限实拍；包围框覆盖本身不能证明所有轮廓像素均正确。
支持当前固定方位透视镜头的横向倍率；改变相机方向、投影或FOV会提示并回退自然模式。
调参预览和录制不是游戏移动的替代；实际路线在自然、柔和、增强与上限模式均完成往返。
参数可产生刻意的层次反转，界面警告但不偷偷改值；最终艺术效果仍需用户选择。
