# 江南河街 · 桥头酒肆

这是独立的 HD2D 光影演示。沿两岸街道行走，经过石拱桥、酒肆、布摊、饮食摊与木码头，与掌柜、摊主、船工交谈。默认角色原样复用 A 角色四方向的 108 张 256×256 颜色帧、帧序、每帧时长、循环和脚底位置。新增的逐帧法线与银饰蒙版用于动态三维受光。

本轮默认使用 F 正面透视：30 米观察半径、35° 纵向视野、14° 俯角、中央偏航 0°。玩家和三名 NPC 在世界中竖直站立，水平面朝主相机；相机俯仰不再让人物倾斜。远景由近镇、远镇、近山、远山、近云、远云六层组成。

## 固定朝向与角色居中跟随 · 2026-10-07

江南场景只提供 F、W 两种固定朝向的透视镜头，水平偏航始终为 0°。开启跟随时，镜头立即对准角色脚底上方 1.0125 米的固定中心，随桥面和码头的实际高度移动。角色动画、发辫和裙摆不会改变这个中心。

地图内部的角色中心保持在画面中央。接近 X=±26、Z=−16～14 的外边界时，对应轴的镜头停止移动，另一轴仍可跟随。离开边缘区域后恢复居中。边缘区域随窗口比例、镜距和 FOV 计算，并按原 108 帧的联合轮廓限制宽度，保留全身至少 2 像素的屏幕留边。房屋、河岸和桥栏的局部碰撞不会触发镜头限位。关闭跟随、固定机位比较和单灯隔离仍可使用。

南侧背景地面从 Z=14 延伸到 46，分别覆盖河槽两侧至 X=±52；水面保留北端 Z=−294，并延伸至同一南端。背景没有碰撞，只与现有岸面和外街面相接，不扩大可行走范围。

设置继续采用 schema 2。完整旧 F/W/O 配置先严格校验，再仅在内存中移除 O；旧活动方案为 O 时使用已保存的 F。F、W 的镜距、FOV 和其他有效设置保留，只有主动保存才写入新的 F/W 配置。直接选择或恢复 O 不改变当前状态；无效设置整体拒绝。

本次检查采用无窗口的物理、投影和设置回归，实际画面由用户在 `scenes/ancient_canal.tscn` 中验证。新的检查记录放在 `build/ancient-canal/center-follow-20261007`。下文录像、性能和交付包仍是各自历史版本的证据，本轮不重新打包、不自动提交或推送。

当前无窗口验证通过：居中专项912项，三种窗口比例下240个镜头／边角组合、25,920次逐帧投影，内部中心误差0像素，边角最小全身留边26.628像素；1584个实际物理样本涵盖四方向、反向停止、桥面及码头。扩宽碰撞159项、场景2273项、设置契约166项、竖直基准825项和背景1022项均通过，原角色与历史Frontal的699个文件摘要不变。`make test`及旧场景／输入回归通过。汇总及逐进程摘要见 `build/ancient-canal/center-follow-20261007/verification-summary.json`；这些结果不证明GPU画面或当前性能。

## 镜头与六层远景

在环境页选择 F 或 W，两组各自保留镜距与 FOV。F 默认 30 米、35° 视野、14° 俯角；W 默认 23 米、45° 视野、12° 俯角。两种方案只平移，不绕转。镜距允许 18–45 米，FOV 允许 25–60°。切换方案保留人物、时段与景深；“恢复当前镜头”只恢复当前组的镜距和 FOV。

“自然”模式使用六层真实位置产生透视视差；“艺术”模式可调整体和每层倍率。自然模式保留艺术倍率设置，实际倍率为 1。近远景深与视差独立控制，“恢复六层远景”恢复默认自然模式。远景装饰没有通路碰撞，桥、岸与码头的物理路线保持固定。跟随时按镜头参数保护人物全身；建筑和天空的构图仍会随镜距与 FOV 改变。

## 光影控制台

控制台分四页，所选灯提供 5 个参数。默认采用黄昏、原生受光与 0.8 法线强度；分档模式默认四档。面板显示当前生效值。手动调光后时段显示“自定义”，切换时段保留镜头与景深选择。

| 页面 | 可观察与调节 |
|---|---|
| 角色材质 | 法线开关／强度／Y 方向校准，原生或 2–8 档受光，灰材质、法线向量、银饰高光，四方向、暂停、上一帧／下一帧 |
| 场景照明 | 时段、主光、环境补光、6 盏灯笼、6 盏街灯、2 盏大范围灯、测试灯、组控与单灯启用／颜色／强度／范围／阴影、单灯隔离和扫光 |
| 环境效果 | 水流、波纹、反光、雾、泛光、SSAO、近远景深、人物焦点保护、F／W、跟随、两组镜距与 FOV、六层自然／艺术视差 |
| 比较与复现 | 同机位法线开／关，固定动画与灯位，恢复默认、保存／载入、截图、自动路线与性能读数 |

建议先在角色材质页选定方向并暂停，打开灰材质，再在照明页暂时关闭测试灯投影阴影并移动测试灯。头发、发辫、银饰和裙褶应随灯位改变明暗。随后恢复动画，观察形体受光是否跟着饰品和裙摆运动。法线向量视图用于定位材料方向，颜色不是人物的新配色。

灰材质扫光录像关闭测试灯阴影、主光、灯笼和街灯，仅保留测试灯与少量白色环境补光，以单独检查法线响应。常规场景保留主光、灯笼、街灯和测试灯的可调阴影；建筑遮挡与真实投影另由场景录像核验。恢复默认可回到常规黄昏照明。

照明页的单灯列表包含 6 盏灯笼、6 盏街灯与 2 盏大范围灯，主光和测试灯另行调节。单灯的五个字段显示实际生效值；普通模式下的修改随显式保存保留。“仅看所选灯”固定人物、机位与灯位，关闭其他灯和主光，保留少量环境补光。隔离期间只通过所选灯字段调光；切换时段、主光、灯组或解除固定状态时，会提示先恢复。“恢复全部灯光”恢复进入前的灯组、单灯修改、镜头与远景设置。路灯组默认只让配置中的两盏投影，其余可通过单灯字段开启阴影。

“比较法线开／关”固定同一机位、姿态与测试灯位置，并切换法线。再次点击恢复之前的参数。角色银饰有独立高光蒙版，布料保留较高粗糙度，不能仅用调亮整体人物判断法线效果。

单灯隔离和法线比较是临时检查模式，两者不能同时开启。期间修改用于当前检查，恢复时返回进入前的配置；期间点“保存设置”也保存进入前的配置。载入设置或恢复默认会结束临时模式。它们不把锁定机位、比较状态或所选灯编号写入设置。

“保存设置”只写入江南河街的独立设置，格式版本为 schema 2，包含 F、W 两组镜距与 FOV、当前方案、六层视差、单灯修改和远景最后使用的时段。夜景调光变成“自定义”后，保存载入仍保留原远景夜色。“恢复默认”恢复黄昏、F 镜头和自然视差。完整旧 schema 2 的三组镜头配置校验后在内存移除 O；活动方案为 O 时改用保存的 F。旧 schema 1 文件保留有效的非镜头设置，旧镜头与单一视差值恢复新默认。两种迁移都只在内存进行，手动保存前不改旧文件。无效 schema 2 文件整体拒绝，当前配置保留。截图保存到本机用户数据的 `screenshots` 目录，状态栏显示结果。设置文件为 `settings/ancient-canal.cfg`。运行无需其他仓库、Blender 或生成服务。
