# Ancient R5 按图施工结果

已按完整俯视图和侧视图应用摆放，保留原有资源及历史审阅稿。用户随后授权提交并推送。本次提交包含布局、资源、来源和验收归档。

[完整俯视图](../../../art_source/ancient-canal/layout-review/20261008-r5/full-top-view.png)、[完整侧视图](../../../art_source/ancient-canal/layout-review/20261008-r5/side-view.png)、[正视图](../../../art_source/ancient-canal/layout-review/20261008-r5/front-view.png)和[灯位图](../../../art_source/ancient-canal/layout-review/20261008-r5/lighting-plan.png)采用同一份施工坐标。[R5 图纸来源](../../../art_source/ancient-canal/layout-review/20261008-r5/README.md)记录坐标含义、模型包围盒和重绘方法。

酒肆、三座民居与三摊退到后岸街道之后，保留酒肆庭院、摊前等候区和连接桥头的巷道。前岸连续步道宽 4.2 米；桥跨度 8.4 米、宽 2.8 米、顶高 0.6 米。码头迁到前岸 X=−12，木板顶面 Y=−0.32，1.3 米缓坡连接前岸。小船停在码头东侧，船工脚底落在木板上。

移除酒肆前的 L5 树，两岸保留五棵平面柳树；酒肆后方及空隙补十座背景屋和十棵平面树。只有前岸两棵树投影，背景无实体碰撞。十四个灯控制 ID 保留，桥心为 C1 冷光，码头 P6 为暖灯、4.5 米范围、默认不投影。主角 108 帧颜色、法线、银饰、动作时序和碰撞保持原样。

路面按材质合并为三组网格，42 个矩形分区同时生成物理地面。码头和坡道处切出地面缺口，避免同高石面和木板叠加。酒肆、房屋、摊位及灯具复用现有模型；低桥另存新模型；[可编辑 Blender 总装](../../../art_source/ancient-canal/layout-assembly/20261008-r5/ancient-r5.blend)保存全部摆放和打包纹理，重新打开的 46 项检查通过。

运行场景图纸核对 74 项通过，验证模型原点、NPC 脚底、近远背景、十四个发光点、灯柱脚点、码头灯隔离及恢复、道路和坡道真实高度。完整 Ancient 场景检查 2068 项通过，实际遍历全部新路线、验证桥与码头双向通行、水域阻挡、酒肆碰撞、五名 NPC 交互及路线完成与取消。镜头、设置和旧场景输入检查另行保存。

实际 GPU 在 Forward+、1920×1080、2×MSAA 下录制最终路线，582 张源帧编码为 69.460 秒完整往返；夜间横移 71 帧、8.495 秒。视频逐包核对源时间并完整解码，没有补帧；采图背压使录像帧率低于运行帧率，录像不能当作性能测量。静止天空上方 30 行像素差为零；F/W 各 24 张码头微机位图中，变化超过 16/255 的像素比例均为零。

实际正交俯视和侧视用于核对施工；平面柳树从正上方会呈边缘，侧视时不同 X 的物体会投影重叠。游戏默认 F/W 镜头保持原构图，天空仅有窄条可见，小弯月可能被云部分遮住。这一可见范围不属于本轮重新摆放的调整。

性能采用独立采样：预热 5 秒、采样 30 秒、三轮交替夜空开关 GPU 对照，另一次 CPU 插桩检查；关闭后台节流，采样期间不截图。逐帧样本、GPU 阶段时间戳、进入夜晚的首次更新及汇总见 [summary](summary.json) 和 [归档校验清单](archive-manifest.json)。前次原纵河与横河的完整对照仍保存在 `horizontal-night-20261008`，本轮数据只归因同一 R5 布局的夜空开关。

可运行 `python3 tools/ancient_canal/archive_layout.py --verify-only` 离线核对已归档文件并重算统计。可编辑模型和图纸各自保留校验清单；本轮没有重新打包整个项目或覆盖之前的性能报告。

## 本机性能结果

设备为 NVIDIA GeForce RTX 4070 SUPER。三轮夜景 GPU 均值的平均为 1.725 ms，P95 的平均为 2.034 ms。

| 夜空新增成本 | 实测 | 预算 |
|---|---:|---:|
| GPU 平均增量 | 0.00825 ms | 0.15 ms |
| GPU P95 增量 | 0.00528 ms | 0.20 ms |
| 天空控制 CPU 平均 | 0.00107 ms/帧 | 0.03 ms/帧 |
| 含原有焦点更新的保守 CPU 计入 | 0.01130 ms/帧 | 0.03 ms/帧 |
| 星空纹理含 mipmap 上限 | 42.67 MiB | 48 MiB |

三轮 GPU 增量和一次 CPU 检查均低于预算。首次时段切换 CPU 为 0.143～0.404 ms，启动阶段 Setup Sky GPU 最大 0.658～0.681 ms；移动采样期间 Setup Sky 最大 0.00836 ms，没有观察到持续重算反射贴图的阶段尖峰。该判断来自实际阶段时间戳，不代表 Godot 内部缓存计数器。
