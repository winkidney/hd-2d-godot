# 江南河街领域契约

新场景入口为 `scenes/ancient_canal.tscn`。布局与资源是独立扩展，旧场景、旧角色适配器和历史验收保持原有含义。

四方向各27帧，每循环1125毫秒。待机下／上／左为10，右为11。脚底锚点 `[128,240]`，世界像素尺寸0.009米。原时间线控制帧更新，法线与银饰不会另起计时器。

法线 RGB 编码为 `vector * 0.5 + 0.5`，X向画面右、Y向画面上、Z向观察者。完整图集 Alpha 与原颜色逐像素相同；环境法线采用各模型 UV 的切线空间。所有文件、来源和运行资源使用工程相对路径。

人物法线的画面基准映射到竖直站立基准：X 为主相机水平右方，Y 为世界 UP，Z 为水平朝向观察者。相机俯仰只改变观察角度，不改原向量图、颜色、银饰、透明轮廓或脚底位置。四方向与待机仍由既有动画规则决定。

码头正式木板与碰撞顶面同为 Y=-0.32 米；正式场景不显示碰撞辅助面，岸面为下沉码头与坡道留空。船工使用当前布局配置的位置，保持原脚底锚点。显示表面不能形成两份共面深度；碰撞通路不能由隐藏装饰代替。

控制台开启、文本输入、弹出选项或退出确认期间，角色输入受控。Tab只导航焦点，带修饰键的事件不调功能；F8／F9保留给编辑器。退出先取消自动路线，再由确认框决定。独立设置路径为 `user://settings/ancient-canal.cfg`。

滚轮只在面板、对话、退出框、自动路线与临时锁定均关闭时改变当前镜头半径，每格0.5米，范围18–45米。FOV独立，范围25–60°；镜头恢复仅影响当前组。单灯隔离／比较退出、载入与恢复默认必须解除相应临时锁定；保存不能把临时检查状态当作用户配置。

开启跟随时，镜头对准固定身体中心，不跟踪动画帧的轮廓变化。地图边界为X=±26、Z=−16～14；边缘带由镜头投影计算，最大为各轴跨度的四分之一，再用原108帧联合轮廓确保至少2像素留边。进入边缘带只限制对应轴，返回内部立即恢复居中；房屋、河岸和桥栏是物理障碍，不是镜头外边界。关闭跟随或进入比较／隔离时保留固定机位语义。南侧地面与水面延至Z46用于视觉覆盖，没有新增碰撞通路。

验收报告记录运行指纹、证据摘要和归因 scope。原十四项范围扩展为十九项，新增 camera_profiles、upright_sprites、distant_scenery、streetlights、dock_stability；功能和像素证据各自归因。源文件发生变化后，旧通过报告不再证明当前版本。完整打包要求四方向循环与扫光、所有通路和交互、参数与设置、旧回归、实际1080p三时段性能和当前独立二进制启动均有可核对证据。

当前角色GPU采样为四方向各三循环、颜色／灰材质共648张1920×1080 PNG；八段角色MP4保留原41／42ms时序，路线MP4按真实墙钟VFR编码。漏采、背压与时长量化必须保留，不能把编码数量当作实时性能。三时段离屏性能和独立ELF空目录启动各有独立报告；总accepted与交付状态只有最终门禁通过后才成立。

调整前的十四项通过记录与旧交付保存在 `build/ancient-canal/history-before-frontal-upright-20261007`。本轮六层引用与第13件街灯模型增加运行资源边界，完整库存和独立 Linux 包须覆盖这些实际依赖；制作工具和其他仓库不进入运行依赖。

## 横向河街更新 · 2026-10-08

Ancient 的 WorldLayout 以 `river.axis=x` 指定横河。`river.center_z`、`bridge.center_x/center_z`、`dock.center_x/center_z/approach_z/surface_y` 同时约束模型与地面、桥面、码头及水域阻挡。边界仍为 X=±26、Z=-16～14。桥是跨河通行连接，码头是前岸的下行支路。驻点 NPC 扩展为五名，现有主角及三名 NPC 来源保持。

PixelWillow 只负责平面视觉，树干碰撞仍由布局负责；背景树不投影。NightSky 缓存昼夜材质，只旋转天空资源，独立于固定的地面与碰撞。启用依据为 `BackgroundRig.profile_id=night`，不是可能变为 custom 的照明标签。SkyFocus 在默认 Forward+ 与 MSAA 条件下只保护天空深度，不改变实体景深和设置 schema 2。

性能前后比较引用各自有效物理路线，夜空归因必须使用同一新布局的开关 A/B。来源、截图与原始性能样本见 [重构报告](../docs/ancient-canal/horizontal-night-20261008/README.md)。
