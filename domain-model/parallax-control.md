# P8 领域契约 · 可调视差

状态：Implemented。自然模式保持P6/P7基线；美术模式按本契约控制五个装饰层。
入口：[P8计划](../Plan/features/adjustable-parallax.md) · [ADR-16](../ADR/16-adjustable-parallax.md)。

## 职责与数据
| 概念 | 职责 | 禁止承担的职责 |
|---|---|---|
| ParallaxProfile | 模式、总强度、逐层倍率、参数过渡时间 | 写场景几何或调用外部服务 |
| ParallaxLayerState | 稳定层ID、节点、原始全局变换、参考深度 | 使用子节点现位置作为下一帧基准 |
| ParallaxController | 由最终相机姿态绝对计算组根偏移 | 按按键或角色速度直接滚动背景 |
| CameraOverrides | 横向跟随、死区、平滑、限幅的可选覆盖 | 更改FOV、道路或纵深层距离 |
| CloudPhaseState | 每层当前风相位与后续风速 | 调速后重新计算历史累计位移 |
| ParallaxSettingsStore | 版本化白名单设置的原子保存/载入 | 读入任意脚本、外部资源或覆盖res:// |
| PreviewSession | 保存并恢复对照扫动前的状态 | 传送玩家或改变物理状态 |
| ValidationSnapshot | 模式、请求/有效参数、相机基准、相位、指纹 | 从用户文件隐式决定测试条件 |

## 倍率与空间
受控层ID为ridge_near / ridge_mid / ridge_far / clouds_near / clouds_far。
natural：k=1；artistic：k=clamp(global_strength*layer_gain,0,2)。不允许NaN、Inf、负倍率或未知层ID。
C0为场景加载参考相机位置，R为固定水平right单位向量；B0为每层未补偿的原始世界位置。
dx=dot(C-C0,R)；B=B0+(1-k)*R*dx。旋转、尺度保持B0的值；写局部坐标时显式换算父变换。
值不变且相机位置相同时输出必须相同；相机返原位时偏移归零；自然模式变换等于原始基线。
只限定横移倍率，纵深移动仍按原透视工作；禁止把k=0表述成取消所有三维运动。

## 更新顺序与单一写入者
玩家输入→物理位置→CameraRig最终姿态→ParallaxController组根→CloudPhase局部位置→DofController→绘制。
背景组根只由ParallaxController写，云子节点只由CloudPhase写；角色/道路/地形/林带不受倍率补偿。
改变倍率使用独立过渡值k_current，不对camera_dx反复平滑；过渡停止后结果须满足公式。
风相位按delta推进后回绕；wind_enabled=false保持相位，暂停镜头不暂停风，冻结测试同时指定两者。
切换时段只更新原有颜色/灯光；切换背景可见性或后处理不得清除倍率、风相位、保存状态。

## UI与保存契约
F8与F6面板互斥，所有可见面板统一阻止手动角色输入；对照扫动是显式临时相机操作。
隐藏HUD时先关闭活动面板、结束对照并恢复控制；Esc优先停止对照/关闭面板，再处理对话或退出。
自然模式保留用户自定义倍率供切回，不丢失编辑；恢复全部默认才重置各参数组。
字段不合法时拒绝该次应用并展示原因；有效倍率达到上限时显示请求值/有效值与限制提示。
保存白名单：schema、layout_id、mode、known_layer_gain、global_strength、transition_time、camera_overrides、wind。
位置、节点路径、代码和任意资源URI不存入配置；实际相位由显式测试快照或会话记录管理。
初始无文件使用项目默认；文件损坏时保留原文件并提示回退，不用错误数据覆盖已有资源。
测试/截图/录制使用显式配置并默认跳过user://设置；成功保存不等于写入项目发布默认值。

## 必须区分的动作
F4关闭跟随：不再按角色更新相机目标；尚在回位/平滑期间仍可能有相机运动及视差。
背景横向视差零倍率：相机继续移动，被控装饰层抵消这一横向位移；近场世界仍正常运动。
F7隐藏背景：只是可见性，不丢失倍率，也不自动更改风状态。
冻结风：只暂停云相位；冻结测试时还需固定水面、相机方向和其他时间输入。
恢复自然：k=1回归原山体位置；不会自动覆盖镜头跟随或云风用户值。

## 验收数据
记录各层B0、C0、R、dx、k请求与有效值、投影深度、预测位移、Godot投影值、像素位移及容差。
几何投影正确不等于像素边缘正确；单独保存真实图像对照和视频、裁剪覆盖与性能记录。
P7默认行程断言只约束自然默认相机配置；用户主动减小跟随倍率时按新目标验证，不伪造失败或通过。
