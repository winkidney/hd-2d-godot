# P9 · 侧面观察实验契约

状态：实现与验收进行中。此文件定义术语和不变量，不将未完成的实际GPU检查写成通过。

## 术语

| 名称 | 定义 | 不应混称 |
|---|---|---|
| ReferenceExperiment | 保留共同场景与路线、独立选择观察机制的一套实验 | 单个镜头参数预设 |
| PerspectiveTranslation | 透视相机固定朝向平移后产生的观察方向变化 | 相机绕转 |
| CameraOrbit | 相机围绕平滑目标做有限水平旋转，半径和俯角不变 | 旋转建筑或改变角色朝向 |
| HorizontalFollow | 初始相机水平轴上的最终平滑位移 | 相机总位移，包含绕转的位移 |
| VirtualCamera | 去掉HorizontalFollow但保留最终朝向与投影的比较相机 | 场景中第二个实际渲染相机 |
| LayerRepresentative | 每个装饰层固定的局部代表点 | 对整个层所有像素的精确保证 |
| MultiviewBuilding | 从同一原创模型生成的离散观察图集，固定建筑脚点显示 | 真实三维侧面、概念整图场景 |
| ComparisonRoute | 所有方案共同使用的物理行走路线 | 用传送拼成的通行证明 |
| PoseSnapshot | 相机显示姿态及跟随、偏航和平滑状态的一致快照 | 只有Camera3D变换的快照 |

## 所有权与接口

`ReferenceScene`拥有当前实验编号、实验切换、F9面板和路线入口。`ExperimentCamera`拥有投影、固定跟随轴、平滑跟随、偏航和最终相机姿态。`ExperimentParallax`拥有装饰层基准变换、代表点、当前倍率、各实验参数快照及投影误差。`ExperimentPreview`暂时控制相机，退出时交还完整PoseSnapshot。`MultiviewBuilding`只替换指定建筑显示，世界继续拥有碰撞。

相机保留既有 `configure/update/set_offset/horizontal_right` 接口，新增 `select_variant`、`pose_snapshot/restore_pose` 与诊断。视差保留 `snapshot/change/reset_all`、面板和存储接口，新增 `select_variant`、代表点误差及全层采样。最终场景切换顺序是：停止预览 → 保存当前实验参数并恢复目标参数 → 重建目标相机姿态 → 立即重算视差 → 切换D建筑显示 → 更新面板。

## 行为不变量

- A为固定透视，B为透视绕转，C为正交绕转，D为固定正交加显式侧面模拟。每种模式在界面中显示真实实现，不允许静默换成其他模式。
- B/C最多±6°，1m死区，死区外10m达到上限，偏航平滑2.5/s。偏航取决于角色位置，不取决于精灵朝向；停止后收敛，回到中心后归零。
- 跟随轴始终取初始相机轴；人物输入仍按最终屏幕方向映射。镜头绕转不能产生跟随反馈。
- 手动切换保留人物世界位置、碰撞实例、时段与景深选择；相机平滑可按新模式重建。各模式独立恢复默认值及保存参数。
- P8只补偿HorizontalFollow。绕转、上下平台和纵深的自然变化保留。补偿从层的基准变换计算，不能漂移累积，也不能影响道路、桥、楼梯或人物。
- 预览冻结世界时钟与水面运动，不移动人物；结束后恢复相机内部状态、时钟、跟随、展示和景深状态。预览失败不能留下锁定或半恢复状态。
- D图集为七个角度×三时段，像素抖动选取相邻视图，脚点锚点固定。碰撞一直保留；丢失图集必须明确阻止进入D，不能展示三维建筑却标为D。
- 干净副本重建引用本次归档原图和确定性配方。原游戏截图与扩展概念图只用于研究，不作为运行场景或纹理。

## 证据与失败情景

代表点误差≤0.1px只证明屏幕横向数学关系；图形标记、全层边界采样和实际截图各自保留。GPU场景检查必须覆盖偏航极值、倍率0/0.5/1/1.5/2、左右/上层/水边路径、三时段及近远景深。正交模式单独检查阴影与景深，不继承透视验收结论。

角色停在镜头限幅处启动预览时，预览给出无可用移动空间的提示并保持原状态。未声明的相机投影、FOV或俯角修改触发可见提示和自然层位置；相机前方无有效代表点的单层保持基准变换。任何这些降级必须记录，不能写成该模式通过。

自动比较可以在起跑前归位，途中必须实际行走并记录目标点与到达点。发生跌落恢复、碰撞卡住或交互失败时保留失败；不能用自动恢复后的最终位置证明路线通过。最终审阅以同路线视频、截图、性能原始样本和对应资源指纹为依据。
