# Project rules

Read Plan/README.md, ADR/README.md and domain-model/README.md first.
Use relative paths; never commit host identities, tokens or build logs.
Never silently replace the renderer, original assets or acceptance evidence.
Keep procedural sources and deterministic seeds for every generated asset.
Run make test and actual GPU capture before claiming visual completion.
No external plugins, global installs, privileged commands or listening servers without approval.
Do not commit or push unless explicitly requested.
