# ADR-20 · A 稿默认角色与四方向行走

状态：Accepted（用户采用 A 稿及授权补齐方向）；新增方向的最终美术审阅与工程验证分别记录。

## 决定

用户于 2026-10-06 指定动画 A 为 HD2D 默认角色，并要求依照项目实际方向需求补生成，保持服饰细节的运动感。共享 PixelActor 在驿站、参考场景、灰盒和正面运河入口统一使用该角色。

项目按镜头空间的主轴选择前、后、左、右四个方向，斜向输入继续归入其中一个主方向。右方向保留已选 A 的 27 张 PNG 及 1125 ms 时间线；左、前、后以同一身份母图独立进行 ImageGen 与 H3 生成，不以翻转右向替代。背面正确遮住正面项链、腰扣和围裙。

每帧原生 256×256，脚底锚点为 (128,240)。固定整段裁剪、二值透明度、每方向最多 96 色共享色板、最近邻采样、无 mipmap、无插帧和逐帧重新居中。Sprite3D 仍受光、深度遮挡、billboard 与接触阴影；像素尺寸为 0.009 m，人物可见高度约 2 m，不改变碰撞体。

行走使用连续完整步态与原帧时长；停止时保留朝向并静止在该方向已审阅的双脚接近支撑姿态。此次没有独立生成待机动作。原有程序化 traveler/hero 与 NPC 图集保留，运行中玩家不再被场景单独改回旧 hero。

## 来源与重建

输入母图、精确提示词、固定种子、变换、完整源视频、连续区间、可编辑 Aseprite 和运行资源散列保存在 [角色来源目录](../art_source/characters/crescent-traveler/v1/README.md)。运行素材独立复制进 `assets/characters/crescent-traveler/v1`，无需生成服务、其他游戏仓库、实验目录或用户主目录。

共享 `scripts/pixel_actor.gd` 的本次授权变更作为 `2026-10-06-crescent-traveler-v1` 采用检查点登记在 [P9 来源状态](../art_source/reference-scene/manifests/source-status.json)。保留 `0673236` 的历史散列，并单独校验当前采用散列、此决定和角色来源。其他 P9 基线检查保持原有约束。

## 验证与限制

`make test` 包含 PNG/图集逐像素、源时序、脚底锚点、四方向物理输入与四入口默认角色检查。实际 GPU 渲染须独立记录，不以无窗口逻辑测试代替。生成画面仍有少量细纹和发梢的帧间差异；A 的用户采用不等于新增方向已经获得逐帧美术批准。

见 [本轮验收](../docs/validation/default-character/README.md)。
