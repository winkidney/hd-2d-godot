# ADR-19 · 保留四种相机实验并按投影补偿视差

状态：Accepted，指用户已接受实验范围与比较方式；最终视觉方案尚未选定。该决策只扩展P9，不改变旧场景的固定相机和既有P8基线。

用户观察到角色移动时建筑会露出不同侧面，要求至少三至四种实现供审阅。我们保留固定透视、透视绕转、正交绕转和正交多视图四套实现，使用共同三维素材、布局与路线。透视平移和真实绕转是不同机制；D的多视图图集则是有意保留的视觉模拟，不能把四套实现简化为几个镜头参数预设。

## 选择与代价

共享P8控制器的契约要求固定朝向及透视投影，直接取消其检查会把绕转位移当成跟随位移，并改变旧场景行为。因此通过P9子类扩展相机、视差和预览，继承已有参数校验、设置快照与面板接口。旧控制器保持原契约；P9显式声明当前投影与偏航，非预期俯角、FOV或投影修改仍提示不兼容并恢复自然层位置。

四种方案拥有独立参数状态。切换和临时预览不会改变人物位置、碰撞、时段或用户的景深选择；预览必须恢复完整相机内部状态。保留多实现增加了测试和打包成本，但能让视觉取舍基于同条件证据，而不是提前淘汰某种技术。

## 代表点投影算法

取最终相机位置 `C`，初始水平轴上的平滑跟随位移 `H`，每层未补偿代表点 `P`。虚拟相机位置为 `C_v = C − H`，朝向和投影与实际相机相同。绕转产生的相机位移保留在二者中，不参与倍率补偿。

实际与虚拟相机的横向屏幕投影分别为 `u_a(P)` 和 `u_v(P)`；倍率 `k` 的目标是：

```text
u_target = u_v(P) + k × [u_a(P) − u_v(P)]
perspective: offset_m = [u_target − u_a(P)] × depth_a / focal_x
orthographic: offset_m = [u_target − u_a(P)] / focal_x
layer_transform = base_transform + camera_right × offset_m
```

相机右轴平移不改变该代表点的相机深度，因此代表点的屏幕X目标可精确满足。每帧从原始层变换重新计算，不累计上一帧偏移。`k=1`保持原世界位置；`H=0`时纯绕转不会移动任何背景根；`k=0`只消除代表点的跟随横移，不消除绕转、云风和自然纵深变化。

这个承诺只适用于代表点屏幕X。透视绕转后不同深度或横向位置的点可能要求不同补偿量，有厚度的整层只能近似。测试同时保留代表点误差和真实mesh边界多点误差，视觉验收另查接缝与覆盖。正交投影的平移补偿无透视深度除法，不能沿用透视公式。代表点处于相机后方或投影异常时不计算危险位移，层保持原世界位置并显示原因。

D使用固定正交相机和独立层倍率，同时将主建筑显示切换为从同一模型生成的七视图图集。图集随观察位置选择，不旋转建筑碰撞；脚点锚点固定。图集只有单个深度平面，不能提供真实立体遮挡和投影阴影，这项限制必须出现在比较报告中。
