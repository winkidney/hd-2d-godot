# P6 · 可控双端景深

状态：已实现并与 P7 联合完成源码 GPU、独立二进制和干净重建验收。
用户授权本轮实施全部已确认规划，不自动提交或推送。

## 范围与边界
使用原生 CameraAttributesPractical，Forward+；不新增插件、不升级引擎。
DofController 独占相机景深字段，LightingController 只拥有灯光、雾、泛光、SSAO。
近景／远景开关独立，正值过渡；两端共享最大模糊量，不伪称有独立原生强度。
默认 standard；soft / standard / strong 为可重复的资源配置。
F5 切换景深；F6 调参；F3 全局旁路保留用户各开关选择；昼夜切换不重置景深。
受保护对焦：清晰区内不追焦，接近边缘时平滑调整。展示用固定场景锚点，另有手动焦点。
先更新最终 CameraRig 姿态，再计算相机空间 -Z 深度，不使用世界 Z 或欧氏距离。
HUD 不参与三维景深；主角保持真实遮挡，不以穿墙显示保障清晰。

## 实施与验收
1. 新增 DofProfile、DofController、运行时面板与三套资源。
2. 与默认开阔相机、步道、远景联合校准；旧参数不直接迁移。
3. 测试配置合法性、单端开关、全局旁路、时段切换、身份保持、焦点死区。
4. 固定相机、角色、云和水，晴昼／黄昏／夜晚比较 DOF 关闭、仅近、仅远、双端。
5. 在实际 GPU 图像中验证近端变化、远端变化及清晰区，不以保存截图成功替代。
6. 固定机位与完整双向行走验收，30 秒连续帧时间记录，独立导出回归。
