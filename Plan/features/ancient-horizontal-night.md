# Ancient 横向河街与夜空重构

用户已确认执行。保持 Ancient 正面 F/W 镜头、角色跟随、108 帧角色及设置 schema 2。本轮不自动提交或推送。

## 场景

地图边界 X=±26、Z=-16～14。横河中心 Z=2.5，宽 5.2 米。后岸一座酒肆、三座民居、三个摊位；前岸连续横向步道。桥中心 X=1.2，跨度 8.4、宽 2.8、顶高 0.6 米，保留石拱、桥墩和栏杆。码头在桥左，顶面 Y=-0.32，通过缓坡接前岸，旁边停船。

地面、岸边水域阻挡、桥面、坡道与栏杆碰撞从同一布局生成。保留旧纵河代码与原桥资源，新低桥独立保存 GLB、可编辑 Blender 来源和重建程序。建筑、摊位、小船及灯具复用项目原资源。背景保留近镇、远镇、山、云六层视差；道路与碰撞固定。

按 R5 保留两岸五棵、背景十棵平面像素柳树，竖直朝向镜头，透明裁切并使用 mipmap。只有前岸两棵树投射阴影。五名驻点 NPC 为掌柜、摊主、船工、食摊摊主、茶客；后两者使用独立新资源和同一脚底锚点、受光方式，不新增行走动画。保留灯具编号、组控制、单灯隔离和比较模式。自动路线经过前岸、桥、酒肆、摊位、码头并返回。

## 夜空

固定种子 20261008 离线生成 4096×2048 无缝全景，含不规则淡银河、暗尘带、不同大小亮度的星点和直径约 0.75° 的细弯月。运行时使用一张缓存全景，不生成噪声或星节点。镜头横移每米 0.005°，限幅 ±0.15°，通过天空旋转实现；停止时稳定，天体相对位置固定，不逐帧修改天空材质参数。

根据背景时段启用夜空，夜晚手动调光成为 custom 后仍保持夜空；昼、暮使用原天空。默认景深保持，天空深度单独保护，见 ADR-22。

## 执行与验收

按资源复核及低桥生成 → 横河与碰撞 → 建筑、柳树、NPC、灯光和路线 → 夜空 → 回归及 GPU 视审 → 性能与归档的顺序执行。

要求 make test、Ancient 场景、设置、镜头和输入回归；实际碰撞验证桥、码头双向通行、水域与建筑阻挡、五名 NPC 交互、路线完成及取消。实际 GPU 证据覆盖三时段、F/W、景深开关、路线端点和完整往返；检查遮挡、闪动、树影、夜空接缝与稳定性。

性能条件为 1080p、Forward+、显式 2×MSAA、关闭后台节流，预热 5 秒、采样 30 秒、交替三轮，截图与采样分开。原布局与新布局各测有效探索路线；新布局另做同条件夜空开关 A/B。预算：天空 GPU 平均增量 ≤0.15 ms、P95 增量 ≤0.20 ms，CPU ≤0.03 ms/帧，新增全景纹理含 mipmap ≤48 MiB。记录进入夜晚的首次更新及行走中是否持续重算天空反射。

资源来源、参数、截图、视频、原始样本及结论独立归档，不覆盖历史 profiling 报告。最终执行结果见 [本轮报告](../../docs/ancient-canal/horizontal-night-20261008/README.md)。
