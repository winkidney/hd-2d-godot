# P8 · 可调视差、镜头参数与本机预设

状态：已实施；源码功能、GPU、像素验证通过。独立包与重建结果以P8验收报告为准。
检查基线：`e64fd44`，`feat: add configurable DOF and parallax exploration`；开始检查时工作区干净。
目标：像景深一样在运行时调节视差，保留 P6/P7 的自然视差、默认开阔探索、30m 横向步道与来源链。
关联：[ADR-16](../../ADR/16-adjustable-parallax.md) · [领域契约](../../domain-model/parallax-control.md)。

## 1. 已确认的现状与问题
`camera_rig.gd` 从 `world_layout.json` 读取 follow_gain=0.45、dead_zone=0.8m、smoothing=4.0/s、follow_max=[7.5,4.5]m。
这些参数能通过编辑文件影响镜头，但没有运行时面板；当前 gain/dead_zone 同时用于横向与纵深跟随。
`background_rig.gd` 的三层山脉固定在世界中，没有逐层视差倍率；有限距离和透视投影决定位移。
`background.json` 只有配色、每层云数量和云风速 [0.6,0.25]m/s，不能独立调山脉视差。
F6 为景深面板、F7 为背景显隐。云位置按 origin + cloud_time * speed 计算；直接改 speed 会改变历史累计位移。
运行时视效配置未持久化。P7 的固定山体断言需区分自然模式和新增的美术调节模式。

## 2. 行为与模式
自然模式为全新启动默认：所有被控层有效倍率 k=1，保留当前山脉位置和自然投影。
美术调节模式允许改变背景横向视差；不会冒称倍率调整后仍完全遵循静态世界几何。
保留原有透视、深度测试、遮挡和景深管线，不增加 Parallax2D、多 Viewport 或背景二维覆盖层。
作用层为近山、中山、超远山、近云、远云。地形、过渡林带、房屋、步道、角色和碰撞保持世界位置。
天空继续按观察方向采样，平移视差锁定为零，不增加天空横向滚动参数。
本轮只增强沿固定探索镜头水平 right 轴的位移；不提供任意旋转、纵深或垂直方向艺术倍率。
整体倍率为零仅冻结上述被控层的横向相机视差；不冻结云风、不冻结近场世界、不等于 F7 隐藏背景。
F3 继续只管理后处理，不偷偷改变几何视差；F4 控制相机跟随，F5/F6 保持现有景深职责。

## 3. 参数规格（范围为待验收候选）
| 分组 | 参数 | 默认 | 候选范围／约束 |
|---|---|---|---|
| 背景 | mode | natural | natural / artistic |
| 背景 | global_strength | 1.0 | 0–2；只在 artistic 生效 |
| 背景 | layer_gain | 五层均 1.0 | 各 0–2；有效 k=clamp(global_strength*layer_gain,0,2) |
| 背景 | 参数过渡时间 | 0.2s | 0–1s；只平滑倍率切换，不额外滞后相机 |
| 镜头 | horizontal_follow_gain | 0.45 | 0–0.7；纵深跟随保留原值 |
| 镜头 | horizontal_dead_zone | 0.8m | 0–3m；纵深死区保留原值 |
| 镜头 | smoothing_rate | 4.0/s | 1–10/s；更大表示更快贴近目标 |
| 镜头 | horizontal_max_offset | 7.5m/侧 | 0–7.5m；缩小不再触发 P7 默认行程下限误报 |
| 云 | 两层风速 | 0.6 / 0.25m/s | 分别 -2–2m/s；0 为暂停该层，反向风须验收循环边缘 |
| 云 | wind_enabled | true | 停止相位推进，不修改已产生的位置或视差 |
界面同时显示请求倍率、有效倍率和达到上限提示，不静默截断而让读数与实际效果不一致。
自然/柔和/增强/自定义预设：自然 k=1；柔和候选 global=0.6；增强候选 global=1.5；内置各层 gain=1。
选择视差预设不擅自修改镜头、风速或景深。恢复全部默认才同时恢复这些组的初始设置。
有效 k=0/0.5/1/1.5/2 指单层自身自然投影位移的倍数，不代表它相对前景的速度比。
不同深度即使倍率相同也不会同速。面板显示代表点当前深度及预计每横移1m的像素位移。
极端组合可能让远层比近层移动快；提示这种层次反转，不以系数大小猜测层次，也不暗中改用户参数。
不把相机 FOV、山体距离／缩放或地形几何混入视差滑杆，避免同时改变构图、裁剪及失焦程度。

## 4. 稳定变换计算
基准为当前场景配置加载后的相机 C0、固定水平 right 单位向量 R、各层原始世界变换 B0。
相机最终姿态 C 更新后，取横向位移 dx=dot(C-C0,R)，层位移 B=B0+(1-k)*R*dx。
固定朝向／FOV、固定深度的纯横移中，屏幕位移为 -fx*k*dx/Z；fx 来自相机真实投影，不写死分辨率。
每帧从 B0 绝对计算，不能将上一帧偏移继续累加；k=1 必须精确回到原始变换。
运行中改倍率会平滑调整背景横向位置，不承诺非基准机位下构图完全不动；完成过渡后回归公式。
节点全局变换与父节点局部变换须明确转换，禁止将整体 BackgroundRig 平移而带动地面和林带。
为三层山脉和两组云提供独立视差根；云风在组内局部坐标更新，控制器只写组根，避免互相覆盖。
云相位按 speed*dt 推进并做周期回绕；调速只影响之后的位移，不能用新速度重算全部历史时间。
相机冻结时被控山体不继续滑动；风冻结和相机冻结是两种独立状态。
C0/R 只在场景初始化或显式重建镜头配置时确定，不在 F4、F7、时段切换或每帧中重设。
倍率只影响横向，在当前固定朝向且无滚转条件下不修改视深度；要验证而不是假设景深始终不变。

## 5. 调参体验与保存
F8 打开独立视差面板，F6 景深面板保留；两面板互斥显示。基本页放模式、预设、总强度；高级页放分层、镜头和风。
滑杆配数值输入、单位、默认值与重置；参数变化实时生效，面板打开时暂停手动角色移动。
提供可选的“镜头横移对照”按钮：在安全范围内沿 R 扫动、冻结风和水面，只观察相机视差。
对照开始保存相机、跟随、时钟与角色控制状态；停止或 Esc 恢复，不移动或传送玩家，不改变地图。
关闭面板后仍可沿现有30m步道左右行走验证，不把调参预览替代正常探索。
一次只使用一个面板/对话输入锁；隐藏 HUD 时同时关闭活动面板并释放锁，避免不可见面板阻塞行走。
提供“恢复自然视差”“恢复全部默认”“保存到本机”“载入已保存设置”；关闭面板不自动写文件。
使用 ConfigFile 保存到 `user://settings/parallax.cfg`，只含版本、已知模式、数值和已知层ID；不回写 res://。
保存使用临时文件和替换，处理失败并保留旧配置；读入后校验类型、有限数、范围、schema及布局ID。
新布局ID不兼容时忽略旧镜头覆盖并明确提示；损坏、未知版本或非法字段不得崩溃或加载任意资源。
无本机设置时自然模式与原P7一致；测试、录制和独立包验证默认忽略本机设置，只读显式测试配置。
保存后重启可恢复；“恢复自然”不删除用户文件，“保存”才确认持久化新的选择。

## 7. 验收矩阵（规范；实际结果见P8报告）
数学：固定相机朝向，冻结风；每层k=0/0.5/1/1.5/2，正负横移与往返，投影应符合 -fx*k*dx/Z。
多次往返无累积漂移；k=1保留旧山体固定变换；k=0消除被控层横向位移但不隐藏背景。
语义：参数上限显示正确；相机冻结后不读角色输入制造山体运动；云调速/反向/暂停时位置连续。
联动：F3、F4、F5、F6、F7、F8、昼夜和展示切换不误清参数；保存不会修改源资源。
人物：自然与三档下既有出生点→桥→步道全程通过；双向行走、两端限位、人物可读与景深保护有效。
输入：切换面板、点关闭、Esc、隐藏HUD、退出对照扫动都恢复正确控制，不出现隐藏面板锁死。
持久化：保存→退出→启动恢复；测试忽略本机配置；非法float/NaN/Inf/缺字段/未来schema/布局变化均安全处理。
覆盖：左右端点及中间、镜头平移全范围、倍率上下限／分层极端组合；检查山脊接缝、云循环边界、裁剪、天空空洞。
超出通过验证的组合不得静默标为推荐；界面提示层级反转／边界风险，必要时收窄发布范围并写明原因。
图像：基准/横移两个机位×三档×三时段，至少18张冻结对照，另录制同一路径倍率对比视频。
同时保留仅近山、仅中山、仅远山的对照蒙版或参考标志，做真实渲染位移检查；几何投影值不冒充图像追踪。
计时：自然、柔和、增强、有效上限组合各至少30秒真实GPU采样；同路径、分辨率、云状态和景深设置。
性能目标仍为1080p / 60FPS帧预算，不能沿用P7性能结果宣称P8已达标。
新证据写入 `build/p8/` 与 `docs/validation/p8/`，独立包在隔离目录重跑配置及恢复测试。
干净副本无用户配置、无缓存导入、默认／自定义档均验证；打包门禁包含参数快照、运行指纹、图像、原始计时、二进制散列。

## 8. 架构兼容与范围边界
本方案需要显式修订ADR-13/15“山脉始终固定”的条款：自然模式继续满足；artistic只对装饰背景应用已说明的相机补偿。
修订在批准实施后生效，本次不篡改既有验收历史。首版不加地形插件、不安装高风险依赖、不推送或提交。
不承诺任意相机旋转/投影方式下相同公式适用；本场景固定方位是前提，检测到不兼容相机时回退自然模式并提示。
默认所有背景层gain相同仍保留深度差；倍率改变的是位移，不改变山体视角尺寸或物理距离。

## 9. 官方依据与推导边界
2026-09-28读取以下官方文档；公式、倍率定义、范围和模式是本项目设计，不是Godot自带3D视差属性。
[Camera3D](https://docs.godotengine.org/en/stable/classes/class_camera3d.html)：透视、最终相机变换、投影和屏幕坐标查询。
[Node3D](https://docs.godotengine.org/en/stable/classes/class_node3d.html)：父空间／全局变换，避免对子节点重复叠加。
[Parallax2D](https://docs.godotengine.org/en/stable/classes/class_parallax2d.html)：scroll_scale是二维能力，本方案不直接给Node3D设置该属性。
[Sky Shader](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/sky_shader.html)：EYEDIR按观察方向采样，不向天空引入POSITION位移。
[ConfigFile](https://docs.godotengine.org/en/stable/classes/class_configfile.html) 与 [数据路径](https://docs.godotengine.org/en/stable/tutorials/io/data_paths.html)：设置保存在user://，不回写发行包资源。
[CameraAttributesPractical](https://docs.godotengine.org/en/stable/classes/class_cameraattributespractical.html)：景深独立保持相机属性职责。
