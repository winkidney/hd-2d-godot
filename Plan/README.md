## 目标与边界
制作原创 Riverside Waystation：参考《八方旅人 II》的像素角色、三维环境、固定探索镜头与冷暖灯光；不复制原作商标、美术或关卡。
首版 Linux 桌面 + 完整 Godot 工程；黄昏/夜晚、可行走、碰撞、招牌调查/NPC 对话、展示/截图模式。
不含战斗、背包、任务系统、网络、Web/Windows 已验收承诺或完全等价于原作的视觉承诺。
目标输出 1920×1080；60 FPS 是待测目标，不是既有结论。

## 实施顺序
先固定相机与桥/旅店主画面，再补场景四周，最后完善动态与交互。
第一轮使用可重建的原创程序化像素素材建立可运行基线。ImageGen 是后续可替换美术生产入口，不伪称已经生成或美术已获批准。
关键模型保留 Blender Python + .blend + .glb。美术处理保存参数、来源与 SHA-256。

## 安全门
不重新安装 Godot/Blender，不 sudo，不 curl|sh，不改防火墙、开机项或其他仓库。
Blender MCP 为第三方任意 Python 执行入口；默认不安装、不启用、不开放 Socket。需用户明确处理后再接入。
导出模板只从匹配引擎版本的官方发布获取并检查官方校验；无匹配模板时标记受阻，交付源码启动包，不冒充独立二进制。
